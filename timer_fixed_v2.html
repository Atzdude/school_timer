Help & Guide
Adding a Timer
1
Type the exam name in the first field (e.g. "Math Paper 1").
2
Type the duration in the second field — e.g. 2h, 1h30m, 90 (minutes), or 1:30:00.
3
Click Add Timer or press Enter.
Quick Duration Buttons
▶
Click any of the preset buttons (1 Hour, 1h 30m, etc.) to fill in the duration field instantly.
▶
Click + Custom (dashed button) to save your own favourite duration.
Bulk Adding Timers
1
Click Bulk Add next to the Add Timer button.
2
Paste one timer per line. Format: Name, Duration — e.g.
Biology Paper 2, 1h30m
Physics Paper 3 (no duration = asks later)
Running Timers
▶
Click Start All to begin all timers at once, or start each individually.
▶
Drag timer cards by the ☰ grip to reorder them.
Saving Sessions
▶
Click Save Session to store the current set of timers under a name. Load it next time from the chips below.
Tip: The app saves your timers automatically. If you close and reopen it, your timers will be restored.
Header Bar
Reading Time Starts a countdown overlay (5 / 10 / 15 min) shown before the exam begins. Hides automatically when done. Use the dropdown to pick the duration.
Presentation Enters fullscreen projector mode — larger text, darker cards, screen stays awake. Press P or click again to exit.
Lock Hides all editing controls so students can't change timers. Click again (or the same button when gold) to unlock.
Fit / 100% / Large Resize the timer cards. Also use the dropdown (Compact → Large) or Ctrl +/-.
Global Actions
Start All Starts every timer that hasn't completed yet. Press Space to start/pause all.
Stop All Pauses all running timers without resetting them.
Reset All Stops and resets all timers back to their original duration.
Clear All Deletes all timers. Use Undo Delete (appears after) to recover the last one.
Keep Done When active, finished timers move to a "Done Shelf" below instead of disappearing after 30 s.
On Each Timer Card
Start / Pause Starts or pauses that individual timer.
✎ Edit Rename the timer. Press Enter or click away to save.
⸻ Reset Resets this timer back to its starting duration.
🗑 Delete Removes this timer. Use Undo Delete to recover it.
Colour dots Pick a colour for the card (navy, burgundy, forest, royal, slate, teal).
Tip: Click the exam name on a timer card to rename it directly.
